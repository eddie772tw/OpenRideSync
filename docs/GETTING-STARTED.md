# 第一版使用流程

官方發行版 APK 透過 GitHub Releases 提供（由發行工作流程注入原服務登入設定，並以 OpenRideSync 專屬發行金鑰簽署）。公開原始碼的預設本機建置未包含原服務登入設定；若自行從原始碼建置，請先從自己的原廠 App 環境取得相關設定資訊，切勿用未配置或不同簽章的產物直接覆蓋既有可用安裝。

> [!IMPORTANT]
> **帳號前置要求**：OpenRideSync 目前版本尚未包含「新帳號首次註冊與服務條款初始化」流程（列為未來版本開發項目）。在登入本 App 前，**請務必先在原廠 Honda RoadSync App 使用同一個 Google 帳號完成首次註冊、居住地選擇與條款設定**。

1. 下載官方發行 APK 後，可先核對隨附的 `.sha256` 雜湊值。安裝並開啟 App 後，在歡迎頁或設定的「關於與建置資訊」確認版本、來源與登入設定，並確認手機與車輛列在該版本的相容性範圍內。
2. 確認你的 Google 帳號已在原廠 RoadSync App 完成註冊後，於本 App 以同一個 Google 帳號完成正常登入，再確認 Honda 帳號與居住地資料讀取結果（若顯示找不到帳號 `NOT_FOUND`，代表尚未於原廠 App 完成初始註冊）。
3. 車輛靜止時，從車庫明確選擇車輛，依系統流程完成配對與保存；保留原有配對資料。
4. 明確連線，分別確認初始化、安全驗證、真實模式與實際儀表顯示，之後再驗證把手與播放器操作。
5. 測試結束後明確停止，確認服務與畫面收尾。有問題時匯出診斷，分享前檢查內容。

旅程錄製與自動上傳預設關閉，需由使用者針對目前帳號明確啟用。真實採樣、上傳接受、回讀與原版可見尚需完整實車驗證；合成資料不能用於上傳驗收。

官方發行版採用固定的專屬簽章，後續官方更新可直接保留資料覆蓋安裝（無須解除安裝或重新配對）。不同簽署身分的 APK（例如自行建置的 debug 版）不能直接作為官方安裝的保留資料更新。
