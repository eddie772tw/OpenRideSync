# 第一版使用流程

目前正在開發第一個面向使用者的 Alpha。公開原始碼的預設建置未包含原服務登入設定；下載或自行建置時，先確認版本說明與配置，不能用未配置產物取代既有可用安裝。

1. 確認手機與車輛列在該版本的相容性範圍內，先閱讀權限與資料處理說明。
2. 以自己的 Google 帳號完成正常登入，再確認 Honda 帳號與資料讀取結果。
3. 車輛靜止時，從車庫明確選擇車輛，依系統流程完成配對與保存；保留原有配對資料。
4. 明確連線，分別確認初始化、安全驗證、真實模式與實際儀表顯示，之後再驗證把手與播放器操作。
5. 測試結束後明確停止，確認服務與畫面收尾。有問題時匯出診斷，分享前檢查內容。

旅程錄製與自動上傳預設關閉，需由使用者針對目前帳號明確啟用。真實採樣、上傳接受、回讀與原版可見尚需完整實車驗證；合成資料不能用於上傳驗收。

不同簽署身分的 APK 不能直接作為既有安裝的保留資料更新。不要為了安裝開發版而先清除資料或解除配對；先確認該版本提供的升級方式。
