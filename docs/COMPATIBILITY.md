# 相容性與驗收範圍

App 最低 API 30，compile／target API 36。車端主線為 Gen1.0／Gen1.5；僅可對已保存且 metadata 支援的車輛明確連線。Gen2 metadata 保持可辨識但不啟動 runtime；不提供 DFU。

研究基線於 2026-10-21 有一次約4分47秒的獨立 App 實車成功。保存的27筆指派回覆、204筆控制回覆與211筆車端功能／模式通知，經 App journal、HCI 與使用者觀察分別核對。這支持當次基本連線、儀表與互動，不能擴張成所有手機、車型或完整功能均已驗收。

公開建置的設定、素材、簽署與研究候選不同，需驗證各自的交付 APK。首版放行仍需補齊：

- 公開且可重複的手機／車型／播放器相容性條目。
- 五次連線與至少一次30分鐘背景／鎖屏穩定性。
- 明確停止、Bluetooth OFF、車端離線、權限撤銷與重連。
- 各項音樂、通話、訊息與真實導航功能的刺激及實際結果。
- 真實旅程採樣、持久佇列、服務端接受、回讀與原版可見。

主機測試、APK 建置與 CI 分別記錄，不能代替上述裝置或實車結果。未知資料、未支援世代與缺少權限均維持明確狀態。
