# 相容性與驗收範圍

App 最低 API 30，compile／target API 36。車端主線為 Gen1.0／Gen1.5；僅可對已保存且 metadata 支援的車輛明確連線。Gen2 metadata 保持可辨識但不啟動 runtime；不提供 DFU。

研究基線於 2026-10-21 有一次約4分47秒的獨立 App 實車成功。保存的27筆指派回覆、204筆控制回覆與211筆車端功能／模式通知，經 App journal、HCI 與使用者觀察分別核對。這支持當次基本連線、儀表與互動，不能擴張成所有手機、車型或完整功能均已驗收。

2026-11-02擷取的後續研究紀錄另有五次成功初始化，四次runtime超過30分鐘，最長約44分鐘；使用者確認尾端全部為結束測試／關車。五次旅程保存203筆位置，14批CreateLocation成功返回且完成本機佇列確認，目前queue為0、沒有in-flight。每日歷史快取有相符日期／時間，尚無這五次的新路徑明細。另有7筆Control非成功回覆待定位，本批HCI已輪替出實測時段。詳細候選、證據與限制見[多次實車回饋](FIELD-VALIDATION-2026-11-02.md)。

公開建置的設定、素材、簽署與研究候選不同，需驗證各自的交付 APK。研究候選的重複初始化及採樣／上傳已有證據，公開交付與其餘驗收仍需補齊：

- 公開且可重複的手機／車型／播放器相容性條目。
- 公開交付APK的五次連線，以及至少一次30分鐘靜置、背景／鎖屏穩定性；研究候選的長時間runtime不替代指定情境。
- 明確停止、Bluetooth OFF、車端離線、權限撤銷與重連。
- 各項音樂、通話、訊息與真實導航功能的刺激及實際結果。
- 新研究旅程的trip／point與路徑明細回讀、原版可見；公開交付APK另驗採樣、持久佇列及服務端接受。
- 七筆非成功Control的命令／raw status／模式對照及根因確認。

主機測試、APK 建置與 CI 分別記錄，不能代替上述裝置或實車結果。未知資料、未支援世代與缺少權限均維持明確狀態。
